# map_template folder

Local scene package for the template side-scroller test map.

## Structure

- `map_template.tscn` - main test map scene.
- `player_controller.gd` - movement/jump/wall slide/wall jump logic.
- `assets/player/` - player visuals (sprite/icon/material placeholders).
- `assets/world/` - world/platform art placeholders.
- `audio/sfx/` - local SFX placeholders.
